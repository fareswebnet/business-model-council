# Adaptateur de projet générique

L'adaptateur transmet au conseil :

- le brief produit et le segment choisi ;
- les identifiants de données autorisés ;
- les hypothèses explicitement marquées ;
- les contraintes réglementaires ou opérationnelles du projet ;
- les preuves client disponibles et leurs limites.

Il ne transmet pas automatiquement tout le dépôt. Les agents reçoivent le minimum nécessaire à leur question. Les chiffres sont rendus depuis la source canonique du projet au moment de l'exécution et sont accompagnés de leur identifiant.

Le conseil peut recommander une modification du modèle, un nouveau pilote ou une reformulation. Il ne modifie jamais la source de vérité du projet.
