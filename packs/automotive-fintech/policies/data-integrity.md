# Politique d'intégrité des données

Le pack métier ne possède aucune donnée financière. Il peut demander une donnée, signaler son absence ou proposer une formule, mais ne peut pas en inventer la valeur.

Pour un projet financier, la source chiffrée est le fichier canonique déclaré par l'adaptateur du projet. Les agents doivent recevoir des identifiants de données ou des extraits autorisés, jamais recopier une valeur dans un prompt permanent.

Toute divergence doit produire une objection traçable et être renvoyée vers le processus de synchronisation du projet. Le conseil ne corrige pas lui-même le modèle financier.
