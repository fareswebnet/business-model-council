# Exemple de demande

Analyse le cas initial d'un logiciel B2B destiné à un segment professionnel étroit.

Utilise trois lentilles stratégiques et trois spécialistes métier configurés dans le projet. Ne fais pas de nouvelle hypothèse chiffrée. Pour chaque chiffre utilisé, demande son identifiant de donnée et son périmètre.

Livrable :

1. thèse d'investissement ;
2. trois objections éliminatoires ;
3. cinq hypothèses à tester en pilote ;
4. deux pivots possibles si le cycle de vente est trop long ;
5. tableau des désaccords entre agents.
