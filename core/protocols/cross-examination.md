# Tour 2 — Contre-interrogatoire

Le coordinateur sélectionne les 5 à 10 affirmations qui :

- changent le marché initial ;
- changent le pricing ou la distribution ;
- portent le plus de risque financier ;
- sont contestées par au moins deux agents ;
- n'ont pas de preuve suffisante.

Pour chaque affirmation, les agents reçoivent la formulation originale et doivent répondre :

1. Quelle prémisse est fragile ?
2. Quelle donnée manque ?
3. Quel test peu coûteux peut trancher ?
4. Quel serait le pivot si l'hypothèse est fausse ?

Les agents ne réécrivent pas les faits du projet. Ils contestent le raisonnement ou proposent une expérience falsifiable.
